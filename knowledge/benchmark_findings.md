# Benchmark findings

Each entry: date, benchmark round, error cluster (tool, class, gene, taxa, n records), cause (with source or 未确证), fix commit, regression check.

## 2026-10-21, Annelida benchmark (40 RefSeq records, MitoM / MitoZ / MITOS2 / MitoFinder) - docs/benchmark_annelida_2026-10.md

- MitoM, boundary_gt30, cox1 / nad6, 4 records (NC_037236, NC_060759, NC_013569, NC_061323): P3 took the first complete stop inside the next protein gene (22-85 nt overlap); NCBI ends with T/TA (source: the records' transl_except). Fix: P3 does not extend > 10 nt into the next PCG (bicistronic pairs excepted), keeps / finds the T/TA stop. Regression: tests/test_mito_curate.py::test_cds_extension_does_not_overlap_following_rrna (rRNA still extended), benchmark exact PCG 383 -> 407 / 517.
- MitoM, duplicate_gene, atp8, 1 record (NC_049135): MitoZ annotated a repeated region twice (identical protein). Fix: D1 keeps one copy. Regression: test_duplicate_pcg_copy_removed.
- MitoM, boundary_gt30, nad5 / nad4l starts, 7 records: NCBI uses the most upstream in-frame start; cob / cox2 / cox3 / nad4 never do (aggressive start on all genes: 407 -> 383 exact). Fix: --aggressive_start_genes ND5,ND4L (default). Regression: test_aggressive_start_genes_only_for_listed_genes; exact PCG 407 -> 414.
- Evaluator, name_error, Leu/Ser tRNAs, all tools: NCBI gene names carry the codon (trnL1(cta)) or the anticodon (trnL(tag)); compared by codon family now (mito_bench_eval.ls_class). 12 -> 5 name errors for MitoM.
- MitoFinder, failed, 3 records: UNVERIFIED reference without CDS (pool filter usable_reference), circular junction trimmed (pad_to_molecule), no megablast hit with the closest available reference (NC_052721 Saccocirridae; genuine limitation).
- Open (未修): rRNA ends differ from RefSeq by 30-80 nt in 13 cases where the RefSeq records are inconsistent among themselves; NC_061743.1 wrong for every tool; 8 tandem trnP copies in NC_060759 (NCBI annotates one).

## 2026-10-22, Metazoa round (173 RefSeq records of 30 phyla for MitoM optimisation; 24 records of 8 phyla for the 4-tool comparison) - docs/benchmark_metazoa_2026-10.md

- MitoM, boundary_gt30 (3' end 100-500 nt short), nad5 / nad4 / nad2 / cox1, 52 genes in 14 phyla (Acanthocephala, Brachiopoda, Ctenophora, Placozoa ...): the cores end the gene at a T inside it (lost C-terminal homology); NCBI ends at the first complete stop, 50 of 52 exactly. Fix: P3 extends an end to the first in-frame stop when nothing is annotated in between (<= 600 nt). Regression: test_p3_short_end_extended_to_first_stop_across_empty_gap, test_p3_extension_capped; 3' ends exact 1881 -> 1937 / 2178 on the 173 records.
- MitoM, internal_stop, 14 CDS (cox1 x6, nad5 x3 ...): 9 have start and end in different frames (core start 1-2 nt off), 2 are antisense copies of the real gene (NC_009082 nad3, NC_014848 nad1), 3 are in-frame (frameshift / nonsense). Fix: P7 frame repair (different-frame ends only), D1 removes an overlapping antisense copy; in-frame cases stay reported (P4). Regression: test_p7_*, test_d1_antisense_*; internal stops 14 -> 8 (the 8 are reported, not hidden).
- MitoM, start codon, nad5 / nad4L: the annelid rule "most upstream in-frame start" is wrong outside annelids (173 records: old start right 52, moved start right 17; Cnidaria 13:0, Nematoda 7:0, Arthropoda 6:2). Fix: mito_curate.py default `--aggressive_start_genes ''`; batch_mitoz.aggressive_start_genes() passes ND5,ND4L for the Annelida clade only. Regression: test_aggressive_start_genes_only_for_listed_genes, test_run_curate_passes_the_clade_option.
- MitoM, start codon, P1 overlap branch (start overlapping the preceding tRNA moved to the next start codon): right when the move is <= 15 nt (31 right / 12 wrong), wrong when longer (14 / 28; NCBI keeps the overlap, nematodes especially: 17 of 142 starts overlap the preceding tRNA). Fix: MAX_START_MOVE = 15. Regression: test_p1_overlapping_start_kept_when_next_start_codon_is_far.
- MitoM, boundary_gt30, nad1 / cox3 ends (24-record set, NC_067900.1 nad1 50 nt into rrnL): P3's "first complete stop within 90 nt" ignored the following feature. Truth (173 records): a complete stop reaches at most 2 nt into a following same-strand rRNA (14 cases), 1-10 nt into an antisense tRNA (41 cases, never deeper); into the next same-strand CDS 11-30 nt: complete stop 17 vs T/TA 6, 31-50: 6 vs 6, deeper: T/TA. Fix: MAX_PCG_OVERLAP 10 -> 30 (same-strand CDS), MAX_FEATURE_OVERLAP 10 (other features) as the limit `reach` for the extension branches; an end with a T/TA tail is not moved past `reach` (an end without any stop signal still is: review C case). Regression: test_p3_first_stop_deep_inside_following_rrna_not_taken, test_p3_complete_stop_up_to_30_nt_inside_next_gene_taken.
- MitoM, P3 tRNA rule checked against the truth (173 records): a complete stop reaching 1-2 nt into the downstream tRNA is kept by NCBI 130 times vs 57 T/TA ends with their first stop at that depth; at >= 5 nt the T/TA end dominates. Current rule (keep <= 2 nt, else T/TA) kept.
- Evaluator, table2asn NoStop x236, all tools: lift_to_ncbi did not move the /transl_except position with the feature. Fix: _lift_except (+ origin-split join). Regression: test_lift_moves_transl_except, test_lift_except_split_by_the_origin. MitoM records with NCBI ERROR 110 -> 37 of 173 after the fix (37 -> 40 after P7 stopped hiding in-frame internal stops).
- Evaluator, name_error, Leu / Ser: the gene number (trnL1) overrode the anticodon; submitters number differently. Fix: ls_class triplet first; 35 -> 28 name errors.
- MitoFinder, failed: reference with a "hypothetical protein" CDS (NC_020459.1, Cnidaria) makes MitoFinder stop -> reference_for_mitofinder() strips unknown CDS; no megablast hit when the closest RefSeq reference is a different order (Lima vulgaris / Pinna rudis, Macrostomum lignano / Taenia ovis): tool limitation, reported as failed.
- MitoZ, unsupported, 6 records: no clade for Cnidaria and Platyhelminthes.
- Open (未修): rRNA ends (MitoM 24 of 46 > 3 nt on the 24-record set; RefSeq records disagree among themselves); start codons where NCBI chose a downstream in-frame start without protein evidence; nematode / acanthocephalan tRNAs missed by MiTFi (ARWEN would add 43 right / 20 wrong on the 173 set - not adopted); NC_027103.1 (Rhodactis, 20 kb cnidarian nad5 with cox1 and nad1 inside its introns) wrong for every tool.
- Result (24 records, 8 phyla x 3; 17 finished by all four tools): protein genes both ends exact MitoM 82.1 % / MitoZ 78.4 % / MITOS2 50.5 % / MitoFinder 59.2 %; rRNA 37.5 / 25.0 / 15.6 / 9.4; tRNA within 3 nt 82.2 / 79.2 / 80.9 / 79.0; records with an obvious error 7 / 16 / 17 / 17; records with 0 NCBI ERROR MitoM 17 of 24, MitoZ 4 of 18, others 0; median s/record 175 / 249 / 385 / 204; peak RAM median 0.73 / 0.49 / 0.95 / 0.24 GB (MitoM's = the MITOS2 cmsearch it runs; the one measure where MitoZ / MitoFinder are lower). Per phylum MitoZ still ahead in Echinodermata (92 vs 87 %) and Nematoda (81 vs 75 %): 1-2 genes each, tRNA-boundary dependent stop choices.
